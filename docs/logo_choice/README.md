# Supplied logo assets — English notes

English translation of the archived [original notes](LISEZ-MOI.txt). Preserve the original package as provenance. The active Juvanga identity is defined in [BRAND](../design/BRAND.md).

FURAKILI and JUVANGA — logos (working proposals):

- `<BRAND>/logos/svg`: vector logos with text converted to paths (no font required). Color, dark-background and monochrome black versions.
- `<BRAND>/logos/png`: the same logos as transparent PNGs, 2,000 px wide.
- `<BRAND>/app-icons`: full square application icons (iOS/Android apply rounded corners themselves), PNG sizes 1024/512/192/180/167/152/120/76/64/48/32/16, favicon.ico, an alternative variant and Android adaptive foreground (432/1024).
- Android foreground background: FURAKILI #1B1F4B, JUVANGA #14213D.
- Fonts: Outfit/DM Sans (FURAKILI), Fraunces/Inter (JUVANGA), SIL OFL license.
- Before commercial use: check OAPI and domains, and establish the official pronunciation.
